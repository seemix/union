# Union v2 — промпти для виконання

Готові промпти для кожного кроку з `docs/ROADMAP.md`. Рішення по проєкту — у `docs/QUESTIONS.md`, розділ 3.

## Як користуватись

1. **Один промпт = одна нова сесія** (`/clear` перед кожним). Кожен промпт самодостатній і сам посилається на потрібні документи.
2. Перед запуском обери модель: `/model opus` · `/model sonnet` · `/model haiku` (вказано біля кожного промпту).
3. Дотримуйся порядку й залежностей (`Після:`). Промпти з однаковою позначкою `∥` можна виконувати паралельно.
4. Після кожного промпту: переглянь diff → коміт у гілку `v2` → постав `[x]` у `ROADMAP.md`.
5. Промпти з позначкою 🔒 потребують даних від людини (доступи, відповіді) — підготуй їх заздалегідь.

### Спільні правила (вже вписані в кожен промпт як «Правила v2»)

> **Правила v2:** Працюєш у гілці `v2` репозиторію Union (фронтенд для ro.baptist.org.md і ru.baptist.org.md на WordPress headless). Спершу прочитай `docs/QUESTIONS.md` (розділ 3 «Рішення») і відповідний етап у `docs/ROADMAP.md` — це обов'язкові рішення, не переглядай їх. Старий код: гілки `romana` (ro) і `master` (ru) — читай через `git show <гілка>:<шлях>`, не перемикайся на них. Стек: Next.js 16, React 19, TypeScript strict. Інтерфейс 1:1 зі старим сайтом. Не комітиш і не пушиш без прохання. В кінці: що зроблено, як перевірити, що лишилось відкритим.
